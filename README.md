# Hi, I’m Chahine

I’m a recent ENET’Com engineering graduate based in Tunis. A lot of what I build starts with something I already do. I made a Premiere Pro panel that jumps to timestamps in client feedback, and I built BVMT Smoker to follow the Tunis Stock Exchange and try out trading ideas with paper trades.

For my final-year project at OX4Labs, I built Synera to answer questions using synthetic patient records and a WHO guideline. I kept those sources separate during retrieval so a reader could see what came from the record and what came from the guideline.
